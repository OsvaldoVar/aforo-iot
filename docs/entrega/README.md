# Entrega — Expediente técnico Aforo IoT

Este directorio contiene la compilación oficial en formato PDF del expediente técnico completo del proyecto **Aforo IoT**, con fecha de corte al **26 de noviembre de 2026**.

## Contenido del documento

El archivo [`expediente-aforo-iot.pdf`](./expediente-aforo-iot.pdf) consolida la documentación técnica del sistema, organizada en las siguientes secciones:

1. **Portada y tabla de contenido**
2. **Problema, justificación, objetivos y alcance**
3. **Usuarios, requerimientos funcionales y no funcionales, casos de uso UML**
4. **Arquitectura del sistema y diagrama de despliegue**
5. **Modelo de datos y diccionario de datos**
6. **Conexiones y montaje del hardware (ESP32)**
7. **Documentación técnica de endpoints de la API REST**
8. **Protocolo y flujo de comunicación IoT (secuencia)**
9. **Manual de instalación, configuración y ejecución**
10. **Manual de usuario de la aplicación móvil (con capturas)**
11. **Reporte de pruebas integrales (API, hardware y aplicación Android)**
12. **Conclusiones, limitaciones, trabajo futuro y referencias**

## Fuente de verdad

Los documentos en formato Markdown almacenados dentro del directorio `docs/` representan la **fuente de verdad** única y versionada del proyecto. El archivo PDF de este directorio se genera automáticamente a partir de dichos archivos Markdown y sus diagramas asociados para efectos de entrega, revisión y preservación documental.
